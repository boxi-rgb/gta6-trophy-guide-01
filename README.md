A fully offline trophy companion for Grand Theft Auto VI. It covers the complete set of 55 official trophies: what each one asks for, how to unlock it, and where it sits on the road to Platinum — all in one page that runs without a network connection.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Everything runs locally; no account, no network, no build step.

## What it does

- **Checklist** — tick trophies off as you earn them, with a live progress bar and per-category counts.
- **Progress tracking** — your overall completion percentage, plus a Platinum roadmap that lays out the sensible order to chase everything in.
- **Saved locally** — progress is stored in your browser's localStorage, so closing the tab loses nothing.
- **Export / import** — back up your progress to a file, or restore it on another machine.
- **Filters** — narrow the list by category, status, or trophy type to find what you're hunting next.
- **Spoiler settings** — hide story details and trophy descriptions until you choose to reveal them.
- **Missable warnings** — trophies that can be locked out are flagged up front, with notes on when to grab them.
- **Two themes** — switch between a light and a dark look to match your setup.

## Data

Trophy names, descriptions, and unlock guidance live in `app/data/trophies.json`, with sources noted alongside each entry.
